6 · Sensitivity analysis

Vary the weight of one criterion from 0 to 1; the other criteria keep their relative proportions. The dashed line marks the current weight.

Priorities, λmax, CI = (λmax − n)/(n − 1), CR = CI/RI with Saaty's RI (n = 1…15). Accept a matrix when CR ≤ 0.10. All calculations run locally in this file.
